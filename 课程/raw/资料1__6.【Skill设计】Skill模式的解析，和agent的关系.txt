是什么

知识多变要溯源就上 RAG;少稳要算数则不必
质量关键
答得准不准,押在「检索捞得准不准」上

Skill 是一段「随取随用的专业知识包」——
平时「睡」在文件系统里，只在相关任务触发时，才被加载进 Agent 的上下文。

平时
静静躺在文件夹里，不占上下文
⚡
触发
任务匹配到描述，被唤醒

注入
操作手册进入上下文，指导执行

APB
一个 Skill 拆开看，就是这三层
①
触发描述   description
写清楚「什么情况下该用我」。本质是给 Agent 的路由信号 —— 它决定 Skill 能不能被正确唤醒。最被低估、最影响成败的一层。
②
主体规程   SKILL.md
具体「怎么做对」。步骤、约束、坑在哪、怎么验证。重点写反直觉、试错才知道的部分。
③
附带资源   scripts / templates
能固化的都固化：脚本、模板、参考文件、示例代码。让 Agent 少现写、少出错。
