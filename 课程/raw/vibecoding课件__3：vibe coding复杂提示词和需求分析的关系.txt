交互层面
• 动效语言（Motion Design） 描述过渡、
反馈、微动画的节奏感。
• "所有动画要慢而丝滑，像黄油融化，不要

• 交互密度（Interaction Density） 点击深
度、信息层级的期望。

一样直接"
• 反馈机制（Feedback） 操作后系统如何
响应。
• "每次完成任务要有一个小小的成就感动画，
但不能打断流程"

V i b e  c o d i n g 产 品 实 战
对于番茄钟
• 动效节奏： 所有过渡 600–800ms，ease-
out，绝对没有弹跳。数字切换时用淡入淡出，
不要滚动翻页效果。状态切换（工作→休息）
时整个背景色有一次极慢的渐变（2秒）。
• 按钮行为： 只有一个主按钮，状态自动切换文
字（"开始" / "暂停" / "继续"）。重置是一个
很小的次级操作，放在角落，不抢注意力。
• 键盘支持： 空格键控制开始/暂停，R 键重置。
这是给真正的键盘用户准备的，不需要任何提
示文字。
• 声音： 用 Web Audio API 合成，不依赖外部
音频文件。声音要像一声轻柔的钵响——单音，
有余韵，2–3秒自然消散。

• 产品： 一个个人财务记录工具
• 用户： 25–35岁，有一定财务意识但不是专业人士，用手机记录消
费，怕麻烦
• 氛围： 高级感但不冷漠——像一本好看的 Moleskine 本子被数字化
了。米白色背景，衬线字体用于金额，无衬线用于标签。没有鲜艳
颜色，只有深绿和深棕作为点缀
• 情绪目标： 记一笔账的感觉要像在日记里写了一句话——轻盈、有
仪式感、不焦虑
• 核心功能： 快速添加一笔支出（3秒内完成）、按天查看流水、月
度总览饼图
• 交互： 添加时只需金额+分类，备注可选。动画慢而克制，数字变
化要有滚动效果
• 文案： 不用"错误"，用"好像哪里不对"；不用"确认删除"，用"移除
这条记录？"
• 技术： React
