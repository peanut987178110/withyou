# WithYou × WorkBuddy 教程计划表

## 教程定位

使用 WorkBuddy，从产品需求出发，逐步搭建一款名为 **WithYou** 的 AI 虚拟陪伴产品。

更新频率：每周 6 天，共 6 周 36 期。

主线：产品需求 → Prompt → 用户记忆 → RAG → Skills → Tools → Workflow → 测试评估 → 产品迭代。

|---|---|---|---|

## 进阶专题

完成 36 期之后，可继续制作以下专题：

- 多语言：十种语言、本地化、RTL、占位符检查
- 语音条：语音输入、转写、消息状态
- 实时通话：T1/T2/T3/T4 通话规则、计费和禁拨机制
- 奖励系统：XP、Lumen、每日三件小事、防重复领取
- 订阅系统：免费额度、Plus、订阅状态机
- 视觉设计：2D 房间、衣橱、角色表达
- 移动端打包：Capacitor、Chaquopy、APK 构建
- 缺陷复盘：记忆泄漏、消息错位、路由意图错误、并发冲突
- 国际化工程：语言键一致性、错误码翻译、语言切换策略
- 产品数据：埋点设计、漏斗、留存和版本分析

## 每期固定内容结构

1. **展示结果**：展示本期完成后的功能或一个真实问题。
2. **产品分析**：说明用户为什么需要它、产品如何验收。
3. **原理讲解**：讲解本期需要的 Prompt、RAG、Skill 或 Workflow 原理。
4. **WorkBuddy 实操**：完成配置、搭建、调试或测试。
5. **指标验证**：用测试案例或产品指标判断是否达标。
6. **版本记录**：更新版本号，记录问题和下一期目标。

## 核心教学主线

```text
用户问题
→ 产品方案
→ Prompt / RAG / Skill / Workflow
→ WorkBuddy 实现
→ 测试验证
→ 指标评估
→ 版本迭代
```

## 建议持续追踪的核心指标

| 指标 | 要回答的问题 |
|---|---|
| 首次有效会话完成率 | 新用户能否顺利体验核心价值？ |
| 场景通过率 | 产品能否稳定应对设计好的需求？ |
| D7 留存与场景复用率 | 用户是否愿意回来继续使用？ |
| 记忆错误率 | AI 是否错误理解或保存了用户信息？ |
| RAG 检索命中率 | 是否找到了正确的资料？ |
| Workflow 完成率 | 多步骤任务能否顺利完成？ |
| 单次有效会话成本 | 交付一次有效体验需要花多少钱？ |
| 风险用例通过率 | 已定义的安全边界能否稳定生效？ |
| 首响时间与 P95 延迟 | 用户需要等待多久？ |
| Skill 触发准确率 | AI 是否在正确的时机调用能力？ |
| Tool 调用成功率 | 外部操作是否可靠完成？ |

## 使用建议

每周提前准备该周最终版本、演示场景、测试用例和素材，再拆分成 6 期录制。每周第 6 期交付一个可体验版本，让观众持续看到 WithYou 从 V0.1 迭代到 V1.0 的过程。

## 结语

WithYou 项目的教学重点，是让观众完整理解：AI 产品不是把模型接上就结束，而是从用户问题开始，经过产品设计、能力编排、工程实现、质量验证和持续迭代，最终形成可用的智能体产品。

### 本计划的预期结果

观众完成系列后，应能理解并复用以下方法：

1. 从用户场景定义 AI 产品，而不是从功能列表开始。
2. 使用 Prompt 设计稳定的智能体行为。
3. 区分上下文、用户记忆、RAG、Skills、Tools 和 Workflow。
4. 用产品指标和测试用例评估 AI 功能。
5. 处理权限、隐私、安全和故障补偿。
6. 通过版本迭代把一个 Demo 逐步变成可展示的 MVP。
