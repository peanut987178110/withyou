# 课程制作约定

- 后续每次生成、重制或修改任何课程，第一步必须完整阅读本目录《课程生成方法说明.md》，按“方法逻辑 + 连续案例 + 操作练习”的标准执行；先完成逐字稿，再制作 PPT，最后逐页核对。本文为简要约定，详细执行方法见该文档。

用户指定：后续每次制作课程前，先阅读本目录《产品经理方法大全.md》，检查 raw 全量目录与更新，结合当课主题精读相关原始资料；不可只凭之前生成的课程续写。

- 依据《AI虚拟陪伴产品_新版课程表.md》确定当课范围、前后衔接。
- PPT 沿用深色高对比科幻风：近白正文、青色与浅紫强调，清晰页码；流程、比较、案例使用不同布局，避免全部变成条目卡片。
- 逐字稿为纯文本，按真实 PPT 的物理页码和标题标注；完整讲解页内要点，并加入自然对话、案例、解释、互动和过渡，不能只是念 PPT。
- 教学虚构案例明确标注，不伪装成真实访谈、统计或现行产品数据。
- 对外称 AI 虚拟陪伴产品，不出现本地项目名称。
- 不附讲师附件、附录、交付物清单；课堂作业可以自然融入末页正文。
- Function Calling、Workflow、Skill、Agent、RAG、Memory、MCP 保持职责边界；不盲目照搬原资料的比喻、旧数据或过度概括。
- PPT 与逐字稿从同一份逐页内容生成，讲者备注同步完整讲稿；校对页码、文字和文件有效性后保存到本目录。
- 保存可编辑制作源，便于后续准确修改；覆盖现有课程是用户授权的修改，宜先备份原版。
